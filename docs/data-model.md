# DAY FLOW Data Model

## Core Entities

- **User**: Profile, preferences, schedule settings
- **Task**: One-off tasks with priority, duration, category
- **Habit**: Recurring habits with frequency, target days
- **Event**: Fixed commitments, appointments
- **Goal**: Long-term objectives with deadlines
- **Plan**: Daily or weekly schedule

## Status Values
PLANNED, STARTED, COMPLETED, SKIPPED, MISSED, CANCELLED, RESCHEDULED, PARTIAL
