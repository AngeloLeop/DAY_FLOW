# DAY FLOW Security & Privacy

## Authentication
- Local authentication only (no server)
- Password hashing using Web Crypto API
- Session management with local storage
- App lock capability

## Data Privacy
- No external tracking or analytics
- No advertising SDKs
- No plaintext password storage
- User data remains local by default
- Optional export with encryption

## Input Validation
- All inputs validated before storage
- No innerHTML or eval() usage
- No arbitrary code execution
