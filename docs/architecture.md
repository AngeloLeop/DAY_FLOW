# DAY FLOW Architecture

## Overview
Offline-first intelligent daily scheduling application built with vanilla JS, IndexedDB, Service Worker, and PWA APIs.

## Layers

```
UI (Templates in index.html)
 ↓
Services (Routers, State, Notifications)
 ↓
DAY FLOW Engine (Scheduler, Conflict Resolver, Optimizer)
 ↓
Repository (Abstract data access pattern)
 ↓
IndexedDB (Local persistent storage)
```
